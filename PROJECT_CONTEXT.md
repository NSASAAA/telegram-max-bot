# Project Context

Проект: универсальный бот для Telegram и MAX.

Цель:
Создать серверную часть бота так, чтобы бизнес-логика была общей, а интеграции с мессенджерами были вынесены в отдельные адаптеры.

Планируемая архитектура:

- общий слой бизнес-логики
- адаптер Telegram API
- адаптер MAX API
- конфигурация через .env
- запуск через Docker
- хранение кода в Git
- позже подключение GitHub
- деплой на VPS через Docker Compose

Текущий этап:
Настройка локального окружения на Mac:
- VSCode установлен
- Codex extension установлен
- Git установлен
- Docker Desktop устанавливается
- GitHub пока временно не подключен из-за 2FA

Технические ожидания:
- язык: Python
- структура проекта должна быть простой и расширяемой
- сначала делаем Telegram-бота
- потом добавляем MAX-адаптер
- бизнес-логика не должна зависеть напрямую от Telegram или MAX

Утвержденная минимальная структура проекта:

```text
telegram-max-bot/
├── README.md
├── PROJECT_CONTEXT.md
├── .env.example
├── .gitignore
├── requirements.txt
├── Dockerfile

├── src/
│   └── telegram_max_bot/
│       ├── __init__.py
│       ├── main.py
│       ├── config.py
│       ├── core/

│       │   └── models.py

    └── __init__.py
```

Желаемый стиль разработки:
- маленькие шаги
- после каждой задачи проверять запуск
- использовать Git commits
- не хранить токены в коде
- реальные токены только в .env
